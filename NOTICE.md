# Distribution notice

CF2GUS is an independent interoperability project. Its release tree contains:

- independently written launcher, tracker, and patch logic;
- low-level GF1 support adapted from the MIT-licensed PRE2GUS project;
- numeric addresses, sizes, IDs, and CRC fingerprints needed to interoperate
  with one verified executable; and
- a built launcher produced from that source.

It does **not** contain the game executable, materialized/unpacked game code,
AMF music, SMP effects, other game assets, cracked-release files, DSMI source or
object code, or an unpacking utility.

The PRE2GUS copyright notice and MIT terms are retained in `LICENSE`. libxmp
was used only as an MIT-licensed behavioral reference for the documented AMF
format; no libxmp source is incorporated into CF2GUS.

*Cannon Fodder 2*, Gravis UltraSound, and other names belong to their respective
rights holders. They are used here only to describe compatibility.
